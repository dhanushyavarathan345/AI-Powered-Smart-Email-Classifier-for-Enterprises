# AI-Powered-Smart-Email-Classifier-for-Enterprises
AI-powered email classification system developed during Infosys Virtual Internship 6.0. This project uses NLP and Machine Learning to automatically categorize emails and detect urgency levels, with a Streamlit dashboard for visualization

AI Powered Smart Email Classifier for Enterprises

📌Project Overview

This project was developed during my Infosys Internship. It focuses on building an AI-powered system to automatically classify customer emails and detect urgency levels.

Enterprises receive a large number of emails daily, including complaints, requests, feedback, and spam. This system helps automate the process, reducing manual work and improving response time.

Features

- Email Categorization (Complaint, Request, Feedback, Spam)
- Urgency Detection (High, Medium, Low)
- Interactive Dashboard using Streamlit
- Data Visualization and Analytics
- Machine Learning & NLP based solution

Technologies Used

- Python
- Machine Learning (Scikit-learn / BERT / DistilBERT)
- Natural Language Processing (NLP)
- Streamlit (Dashboard)
- Pandas, NumPy, Matplotlib

Project Modules

🔹 Module 1: Data Collection & Preprocessing

- Collected and cleaned email dataset
- Removed noise (HTML, stopwords, signatures)
- Labeled data with category and urgency

🔹 Module 2: Email Categorization

- Built classification models
- Multi-class classification (4 categories)
- Evaluated using accuracy, precision, recall, F1-score

🔹 Module 3: Urgency Detection

- Predicted urgency levels
- Used keyword + ML approach
- Improved accuracy with hybrid method

🔹 Module 4: Dashboard

- Built using Streamlit
- Filters by category, urgency, date
- Visual analytics (charts, trends)

🔹 Module 5: Deployment

- Deployed on cloud (Azure/AWS/GCP)
- API integration for real-time classification

Outcomes
